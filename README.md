# 🧹 Dev Cache Cleaner (Windows)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![C++17](https://img.shields.io/badge/C%2B%2B-17-blue.svg)](https://en.cppreference.com/w/cpp/17)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-0078D6.svg)](https://www.microsoft.com/windows)

Безопасная, честная и быстрая консольная утилита для очистки диска C от мусора, который оставляют разработчики, браузеры и система. 

## 🛡️ Главный принцип: Только кэш

*   **Утилита удаляет ТОЛЬКО кэш и временные файлы**, которые при необходимости скачаются заново.
*   Ваши личные данные (модели ИИ, настройки Adobe, проекты, сохранения игр, куки и пароли браузеров) **остаются в полной безопасности**.
*   Все удаляемые пути проверяются на безопасность (защита от удаления `C:\Windows` или корня профиля пользователя).
*   В коде нет уровней `[DATA]`, которые могли бы случайно затронуть что-то важное. Только `[SAFE]` и `[REBUILD]`.

## ✨ Особенности

*   **Уровни доверия (Trust Levels)**:
    *   `[SAFE]` — безопасно удалять (кэши браузеров, Temp, NVIDIA DXCache, кэш эскизов Проводника).
    *   `[REBUILD]` — зависимости (npm, pip, Maven, Gradle, NuGet). Удаляются, но при следующей сборке скачаются заново.
*   **Сжатие WSL2 и Docker (VHDX)**: Главная киллер-фича. Утилита автоматически запускает `fstrim` внутри всех ваших WSL-дистрибутивов и сжимает виртуальные диски через `Optimize-VHD`, освобождая десятки невидимых гигабайт.
*   **Защита от системных ошибок**:
    *   Не удаляет симлинки (чтобы не затереть данные на других дисках).
    *   Использует `Job Objects` для гарантированного завершения зависших процессов сжатия без утечек хэндлов.
*   **Честный отчет**: Пересчитывает размер папок *после* удаления. Если файлы были заблокированы (например, открыт Chrome), вы увидите `[ЗАБЛОКИРОВАНО]` или `[ЧАСТИЧНО]`, а не ложный успех.
*   **Режим `--dry-run`**: Показывает, сколько места можно освободить, ничего не удаляя. Идеально для первого запуска.

## 🛠️ Сборка

Для сборки требуется компилятор с поддержкой C++17 (MinGW или MSVC).

**С помощью MinGW (g++):**
```bash
g++ -std=c++17 CacheCleaner.cpp -o cleaning.exe -lole32 -lshell32 -ladvapi32
```

**С помощью MSVC (Developer Command Prompt):**
```cmd
cl /std:c++17 /EHsc CacheCleaner.cpp
```
*(Библиотеки `ole32`, `shell32` и `advapi32` подтягиваются автоматически через `#pragma comment` в коде).*

## 🚀 Использование

Запустите скомпилированный `cleaning.exe` от имени **Администратора** (это необходимо для очистки системных кэшей и работы `Optimize-VHD`).

```cmd
cleaning.exe [опции]
```

**Доступные опции:**
*   `--dry-run` — Режим разведки. Программа покажет список кэшей и их размер, но ничего не удалит. Идеально для первого запуска.
*   `--help`, `-h` — Показать справку.

**Интерактивный режим:**
После сканирования утилита покажет таблицу найденного мусора и спросит:
*   `y` — удалить найденный кэш.
*   `n` — отмена.

## ⚠️ Известные ограничения и нюансы

1.  **Сжатие VHDX (WSL2/Docker)**:
    *   Требует **Windows Pro или Enterprise** (наличие модуля Hyper-V). На Windows Home утилита вежливо пропустит этот шаг.
    *   Для сжатия требуется свободное место на диске (до 2x размера самого VHDX), так как `Optimize-VHD -Mode Full` создает временную копию.
    *   Сжатие останавливает все WSL-сессии. Незакоммиченная работа в терминалах будет потеряна.
2.  **Переменная окружения `WSL_UTF8`**:
    *   Утилита корректно парсит вывод `wsl -l -q` в форматах UTF-16LE и UTF-8 (если установлена переменная `WSL_UTF8=1`). 
    *   *Нюанс:* Если вы установили нестандартное значение (например, `WSL_UTF8=TRUE`), имена дистрибутивов могут отобразиться некорректно.
3.  **Job Objects**:
    *   Если запустить утилиту внутри другого Job Object (например, из-под отладчика Visual Studio или CI-агента), привязка дочерних процессов может не сработать. Программа выдаст `[WARN]`, но продолжит работу.
4.  **Windows Prefetch**:
    *   Очистка `Prefetch` может немного замедлить первый запуск программ после очистки (Windows будет заново строить кэш). Программа предупреждает об этом в списке.
